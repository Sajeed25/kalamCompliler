# Teacher guide

Students never need an account for free coding. Classes are only for assignments and
saving stars across devices.

## 1. Create your account
🔑 **Log in → I'm a teacher → New teacher? Create an account**. You need the *school invite
code* from your Kalam admin.

## 2. Create a class
On your dashboard, type a class name (e.g. *Grade 5 – A*) and press **Create**. You get a
6-letter **class code** like `K7M2QP`. Write it on the board.

## 3. Add students and print PIN cards
**Students → Add students**: type first names, one per line → **Add and make PINs**.
A sheet of PIN cards appears. **Print it now**: PINs are shown only once. If a student
forgets theirs, press **New PIN** next to their name.

Students log in with: class code → tap their name → type their 4 digits.

## 4. Make an assignment
**Assignments → New assignment**:
* Title, instructions, language, optional starter code (or *Copy from an example*).
* **Tests**: for each test, what the student's program will read (one answer per line), and the
  exact output you expect. Tick **secret** to hide a test's details from students.
* **Check**: *must match exactly* (spaces at line ends and blank lines at the end are ignored)
  or *must contain the expected text*.
  * Python: the text of `input("...")` prompts is **not** printed during checks, so expect only real output.
  * C/C++: `printf("Enter a number: ")` prompts **are** part of the output. Include them in the
    expected output, or choose *must contain*.
* Press **Try tests on the starter code** to check your tests before saving.

## 5. Watch progress
**Submissions** shows each student: ✅ all passed / 🟡 some passed / — not tried, the number
of tries and the time. It refreshes every 20 s during class. **View code** shows the code they
last submitted. **Download CSV** exports the table.

## Tips
* Python works even if the internet drops (after the first visit). C/C++ need the server.
* The 🏅 badges page shows each student's *own* progress. There are no class rankings.
* The settings ⚙️ menu has bigger text, dark mode, a dyslexia-friendly font, and Telugu/Hindi.
